# Calendar port contract

- Donor: https://github.com/kcsujeet/ilamy-calendar/tree/04e34d17cb6db097c034bba04655353bcc38fe7c
- Scope: thin Calendar App shell; pinned month/week/day/year calendar, donor navigation/grid/rendering/drag behavior and recurrence plugin. No resource scheduling, documentation playground, account features, external service, or invented demo records.
- Demo: all 23 base events, including two recurring series. Frozen reference instant 2026-10-11T00:00:00.000Z; occurrence counts depend on visible date range. See docs/DONOR_DATA.md.
- Room: calendar-port; one calendar_event document per base event or saved exception. No automatic sample seeding. The operator installs the reviewed schema and exact licensed sample once.
- Persistence: host Room replica only. Native observed Room Drafts hold raw field edits; explicit Save validates and queues. Recurring form edits and drags use the donor this/following/all scope choices. The selected related documents become native drafts and require explicit atomic Save. Form scope selection precedes typing so partial fields always belong to real business drafts. New This override identities are stable per series/occurrence across concurrent tabs; vendor mutation logic remains unchanged. Shared same-browser CAS retries reread current native drafts, retains disjoint fields/sections and first field bases, and applies last local input. Provider unavailability or write halt does not prevent local drafting or Save; no Provider Actions are needed.
- Safety: first sync completion and one Room binding are required. Missing binding clears displayed business data. Refused or stale saves retain native drafts. No automatic discard, rebase or off-Room recovery storage. Runtime Presentation holds document/path references only; it cannot restore any business content after native drafts disappear. Scoped form reopen hydrates the referenced native drafts, preserves their original bases/sections, and refuses incomplete bundles. A cleared Runtime connection refusal rechecks actual Room/sync readiness; an active denial or reported storage loss remains blocking.
- License: root donor MIT notice retained exactly; dependency notices include installed production closure. No donor images or external assets required.
- Verification: local boundary/DOM tests are not hosted browser acceptance. Hosted desktop/360px, offline/reload/multitab behavior and exact hosted network requests remain acceptance checks until independently run.

## Recurrence fidelity and limits

See `docs/RECOVERY_AND_RECURRENCE.md`. All-series edits preserve the original date anchor, clear EXDATEs and remove detached overrides; following edits split the series and may remove later overrides. The pinned fixed following ID can collide after a repeated split, which is refused. Distinct unfinished scopes sharing the same event paths are refused rather than mixing their bundles. No recurrence-rule editor, standalone Delete, resize handles, import/export, resources, or generic drag-batch resume UI is added.
